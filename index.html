Chain & connection
Scoped to Ethereum for now — Base, Arbitrum, Optimism, Polygon, and Zora are wired in the code but hidden until you want them turned back on.
Public RPCs are slow and rate-limited under mint load — this is the #1 cause of missed mints. Use your own Alchemy/Infura endpoint.
OpenSea's own docs say their API key can't be safely used in a browser, and their API blocks direct cross-origin calls anyway. A tiny serverless proxy (e.g. Cloudflare Worker) holds the key server-side and fixes both — see the worker.js file provided alongside this app.
Calling OpenSea directly from the browser with this key will often fail (CORS) and isn't how OpenSea recommends using API keys. Set the proxy URL above instead if you can.
